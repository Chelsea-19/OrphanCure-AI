# OrphanCure Case Studies

This folder contains manually reviewable OrphanCure case-study artifacts.
Phase 6D selected representative examples from the completed 20-pair
full-agent run, while the original template files are retained for future cases.

Do not replace `TODO_MANUAL_REVIEW` with biomedical claims until the repoDB
label, Open Targets evidence, PrimeKG paths, PubMed literature, generated
claims, and citations have been reviewed by a qualified human reviewer.

Selected Phase 6D artifacts:

- `case_inventory.csv`
- `selected_cases.csv`
- `case_01_correct_positive.md`
- `case_02_correct_negative_or_failed.md`
- `case_03_verifier_effect.md`
- `case_04_incorrect_but_informative.md`
- `case_05_partial_success_optional.md`
- `case_studies_en.md`
- `case_studies_zh.md`

Template files:

- `approved_positive_case.md`
- `failed_negative_case.md`
- `uncertain_mechanism_case.md`

Each case separates evidence source, interpretation, safety notes, and manual
review status. These files are for research and educational purposes only. They
are not medical advice and must not be used for clinical decision-making.
